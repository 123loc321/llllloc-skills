The from Figma rule (29 Sep 2026).
- Only when he types `export`: the NEWEST version of the Figma design goes out as JPG to `2_GRAPHIC ASSET/*From Figma/`. Never on its own. Make the folder the first time.
- One subfolder per group, in UPPERCASE, named for the Figma section or part: `PART-1/`, `PART-2/`, `MAP/`.
- Name: `Figma_<Client>_<Project>_<FRAME>_V<n>.jpg`. `<Client>_<Project>` is the project folder name without its date. `<FRAME>` is the frame name without its version tag. `V<n>` is the frame's version in Figma (`_v3A` becomes `V3A`). No date or time.
- How to export: `llllloc:tool-figma` 13.
