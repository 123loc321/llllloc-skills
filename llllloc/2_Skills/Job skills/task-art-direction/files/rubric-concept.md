# RUBRIC: CONCEPT

JOB: score concept territories or a treatment before he sees them.

INPUT: the territories or treatment file, the brief file (with its STATED and ASSUMED lists), the brand file.

STEPS: score every line 1 to 5 for each territory. Quote the line that earns the score.

OUTPUT: the scored table per territory, the default test, the fixes.

RULES
- R1. Never praise an idea. Why: the critic is there to find the weak point. Check: does the report hold zero compliments?
- R2. The competitor test. Why: an idea that fits any brand belongs to no brand. Check: was the brand name swapped for a competitor's, and does the idea still work? If it does, C4 scores 2 or lower.

CHECK: every territory has every line scored.

| # | Line | 5 means |
|---|---|---|
| C1 | One sentence | The idea can be said in one sentence with a clear mechanism. |
| C2 | Solves the brief | It answers the real ask in the brief, not only the look. |
| C3 | Really different | Each territory differs from the others in idea and story, not only in palette. |
| C4 | Ownable | Swap in a competitor's name and it stops working. |
| C5 | Not the default | At least two of three territories are NOT the first idea a model or an agency would give. |
| C6 | Visible | Each territory names concrete pictures: a lens, a light, a material, a move. No adjective piles. |
| C7 | Makeable | It fits the stated budget, time and tools (AI generation, Cavalry, edit). |
| C8 | Scales | It works as a hero film, a cutdown and a still. |
| C9 | Pre-mortem | Imagine it failed six months after launch. The likely reason is named and handled. |
