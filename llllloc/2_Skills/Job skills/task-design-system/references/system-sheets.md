# SYSTEM SHEETS — build the system, not the job, then stop

Part of `llllloc:task-design-system` SHEETS. Read in full before any sheet set. Craft, visitor mode and the direction rules: `llllloc:task-design` RULE 0, RULE 4 and `references/directions-and-runs.md`.

## What one sheet shows

Three or four sheets. Each one rendered, each one a different kind of answer to the brief, never three shades of one idea. One sheet holds, in this order:

1. THE NAME and one sentence a crew could act on. Never an adjective.
2. THE PALETTE: 4 to 6 hexes, one role each (dominant, support, accent, neutral, ground). One accent. A color with no role is cut.
3. THE TYPE: display, supporting, microcopy, each with family, weight, size and case. Three levels, named.
4. THE GRID: columns, margins, the spacing step, the hang line.
5. THE SHAPE LOGIC: radius, stroke, shadow or none. One era, one voice.
6. THE SIGNATURE: the one element you would recognize out of context.
7. THE MOTION RULE, on any job that moves: enter and exit easing as cubic-bezier, the duration step, the one signature move and the VO word it lands on.
8. ONE PROOF PIECE PER MEDIUM the job has:
   - UI or website: one key screen, plus a button, a card and an input in every state.
   - Deck or slides: the cover plus one content slide.
   - Poster or key visual: the hero frame.
   - Storyboard: the frame template plus two frames with lens and light.
   - Film or motion: one style frame plus the motion rule, and the four showreel lines (`llllloc:task-motion` `references/showreel-brief.md`).
9. WHAT IT IS NOT: the nearest cliché for this category, named and refused.

A sheet with no proof piece is a mood board. It does not ship.

## How to render

Default: one HTML page, all sheets side by side in a grid, one line of trade-off under each, at final size, with real fonts (Google Fonts only) and real hexes. Publish it as an artifact when the session can, else write the file to the job's `*_CLAUDE/3_Art Direction/Directions/` and screenshot every sheet at 100 percent for your own check. Open every sheet and look (RULE 2 of `llllloc:task-design`): squint test, contrast numbers, measure. Fix before it ships.

He names Figma: build the sheets as frames in one new yellow section, duplicated from nothing in the client file, through `llllloc:tool-figma`. Never edit an existing frame in place (core hard stop 3).

An AI-made element in a proof piece: `llllloc:task-design` RULE 8 writes the art direction lock for the prompt, then `llllloc:task-prompt`. Magnific renders run at once on the project's space (core hard stop 1).

## The stop

The reply holds the sheets, numbered, one trade-off line each, then one question: which one, or what to change. It holds no plan, no build, no "meanwhile I started". End the turn.

He answers with a number: WRITE V1 from it the same turn. He answers with criteria ("the first, with the type of the third"): merge, render the merged sheet once for his eyes, then WRITE V1 the same turn. He answers with a new reference or a word that changes the brief: one more sheet set, never a fourth round without saying the pattern has not landed.

## Check before the sheets ship

- [ ] Three or four sheets, different in kind
- [ ] Every sheet rendered and looked at at final size
- [ ] Every color has one role, one accent per sheet
- [ ] Three type levels named with family, weight, size, case
- [ ] A proof piece per medium the job has
- [ ] A motion rule on every job that moves
- [ ] The cliché named and refused on every sheet
- [ ] The reply ends on the question and on nothing else
