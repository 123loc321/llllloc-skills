# llllloc:references-art — tests

1. Drop a Spider-Verse frame with "this style": expect the devices named with numbers (halftone frequency and angle from the FFT, colour offset, hatching, twos) and no "Spider-Verse style" in the prompt lines.
2. Drop a Ghibli background: expect medium read as poster colour or gouache-like with the CLIP hint and its percentage, value groups with shares, gamut spread, and a note that there is no line to measure.
3. Drop an ArtStation character sheet: expect shape family, silhouette test, heads tall by eye, line width median and taper, and the artist found by reverse search with the software used from the page.
4. Drop a photo by mistake: expect a one-line redirect to llllloc:references-photo and no art measures run.
5. A client's own mascot with "draw more of this": expect the sheet to carry the character as given, no rights line.
6. A manga page: expect line hierarchy, screentone read as halftone with its frequency, panel grammar in COMPOSITION.
7. Reply ends with core rule 9's two lines; every number has a source or `~`; OPEN names what was not measured.
