# Rule 13: the research pass questions

Moved from SKILL.md on 14 Oct 2026, unchanged. Read at the research step of every design turn that runs the pass.

## RULE 13 — THE RESEARCH PASS. Every design turn, first or revision.

`llllloc:task-research` runs with this skill on every design turn, tagged or not, as it does on every prompt turn (27 Sep 2026). It runs after RULE 6 and before RULE 0. It skips only on a recreation (RULE 0), or on a text edit, a recolor or a nudge that names no new reference, look or tool.

The METHOD pass always asks three questions:

1. THE REFERENCE. What is the look, work, studio or case he dropped or named, and what makes work read as it? Find its source (case page, Behance, Dribbble, the studio site). Open every image at full size. Name its traits: ground, color roles, type (family, weight, size ratio), shape and radius, surface and shading, stroke width, icons, data marks, motion. A thumbnail chooses a reference. It never describes one.
2. THE GRADE. What separates the premium version of this look from the cheap one? Practitioner sources, not listicles. The words "premium", "not slop" and "generic" in his message always open this question.
3. THE PROGRAM. How does the program he builds in make it best, and where is its wall (an effect Figma cannot set, a blur limit, a font it cannot load)? A tool behavior is a fact (RULE 5).

THE CACHE FIRST: `llllloc/5_Research cache/jobs/design/_TOPICS.md`, then only the topic files this job needs. A line under 60 days old on the same question is the answer. The budget and the search rounds are `llllloc:task-research`'s.

THE FINDINGS MUST CHANGE THE BUILD. The reply opens with the `FINDINGS` and `METHOD` block from `llllloc:task-research`. Each METHOD line names what it changed in the design. "Changed nothing" is a valid answer. A finding that changed nothing is not dressed up as one.

FILE IT: one cache line per question, the same turn, unasked. A named look that he will reuse also gets its trait list in the job's `DESIGN-SYSTEM.md` (RULE 9).

Never write a receipt for research that did not happen. A reference studied is a fetch or a read in this transcript.
