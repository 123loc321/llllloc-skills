## THE TEMPLATE
The master folder is `~/Desktop/Claude/llllloc/7_Templates/render-preview/`. It holds `Render_Preview_Template.html`, plus `plugin/` with `clip_server.py`, `notes_server.py`, `Start clip server.command` and `Start notes server.command`. It is the client V1.5 breakdown page as he approved it (26 Oct 2026, his words: "update the skill to so you remember this template for future use"), rebuilt in the Review Studio design (31 Oct 2026). Copy the folder, change only the data block, the title and the notes file names, and keep every behaviour below:
- Each clip is a `<video muted playsinline autoplay>` built only while its card is on screen. Off-screen clips are unloaded, so the decoder never fills up. Chrome's real player cap is 1000. The old 75 limit is from 2021.
- **Pairs loop together, by hand.** The clips set `loop = false`. When one clip of a pair ends, it waits on its last frame for its partner, then both start from frame 1. A timer that seeks to fix drift left pairs 0.35 s apart. The hand-made loop kept them within 0.01 s.
- Sources are tried in order: `clips/<id>.mp4`, `clips/<id>.mov`, then the local clip server `http://localhost:8765/<id>.mp4`, then the job's own render folders. A clip with no source becomes an orange "clip not found" card with its id.
- Controls sit in one bottom pill, off the pictures, each showing its key: Space plays or pauses all, R restarts all in sync, 1 2 3 set ¼× ½× 1×, - and = change the size, plus Send all. A mono status line sits at the top right ("75 playing · 82 cuts · 7 missing").
- Click a card to open the close-up: both versions large, side by side, the same pill, frame step with the arrow keys at the job's fps, timecode counted from the cut's IN.
- **Whole video first in each row** (his ask, 26 Oct 2026). A WHOLE VIDEO card comes before CUT 01 and plays the full edit (`<block>_OURS_FULL.mp4`, `<block>_CLIENT_FULL.mp4`). It is paired and synced like the cuts. It sits on a raised white tile, with "FULL · <real length> s" in mono, a thin orange progress bar, and "now: CUT NN" worked out from the cut timecodes. The status line reads "82 cuts + 12 full".
- **Nothing sits on the picture.** The whole-video card is marked by its raised tile, never by a line over the video. The row strip scrolls sideways and clips what is outside its box, so the strip keeps padding for the tile shadow. Clips stay in full colour on a wall: the Review Studio gray thumbnail rule applies to thumbnails, not to the pictures under review.
- **Notes.** There is a note box under every OURS card and under the whole-video card. Each box is the Review Studio note box: orange ring on focus, orange 26 px send circle. Return sends, Shift Return makes a new line, and Return does nothing while a Vietnamese word is being typed. The pill has "Send all notes (N)" (Shift+Cmd+Return), which sends every unsent note in board order as one list. The line under a box shows one of these states: draft; "sent to Claude · HH:MM" in gray; "changed, not sent"; or orange "not sent, notes server is off", with the text kept. Typing in a box never fires Space or R.
- Notes go to `notes_server.py` on port 8766. It writes two files next to the page: `<Client>_<version>_Notes.json` (the latest note per cut) and `<Client>_<version>_Notes_log.md` (every send, with its time). This session watches the log with a background `tail -f` and reads each send (untested, Mac test list). A claude.ai Artifact cannot replace this, because its rules block video from his Mac (26 Oct 2026).

## STEPS
```
- [ ] 1 Cut list read
- [ ] 2 Clips ready
- [ ] 3 Page built from the template
- [ ] 4 Look checked
- [ ] 5 Tested in a browser
- [ ] 6 On the Mac and open in Ego Lite
```
1. **Cut list.** Take the cut names, IN and OUT timecodes, fps and source clip notes from the job: the cut list JSON, the Figma board text (one read-only `use_figma` dump of the text layers) or the EDL. Never retype timecodes from memory.
2. **Clips.** One H.264 MP4 per card, `yuv420p`, no sound track, at display size (720x960 for a 3:4 card), named `<block>_<ROW>_<NN>.mp4`, all in one `clips/` folder. Encode with ffmpeg in Bash when only full-size renders exist. The two whole videos per block come from our full render and from the client's own export master. Find the master by matching a cut frame to it (over 40 dB PSNR), and never guess. Our whole video and the client's must have the same frame count.
3. **Build.** Fill the data block: blocks, rows, cuts. Title: `<Client> <version> <kind>`. Name the file `<Client>_<version>_<Kind>_Autoplay.html`, other naming rules in `llllloc:task-files-organize`. Then run `python3 -I plugin/sync_design.py "<page>"`: it copies every token of the live page into this page and prints the system version. No output line: go back and run it. The live page changed something the tokens do not carry, such as a note box or a motion: copy that CSS across by hand.
4. **Look.** `llllloc:impeccable` loads with this skill. Check the page against the system, top rule 0: ground #F2F2F3, surface white, text #1D1D1F, support #636366, one accent #FF3300 that marks only where he is. `system-ui` and `SF Mono`, no web fonts, 11 px floor. Radius 16, 12, 8, 24. No glass, no blur, no glow. Phosphor regular icons. Any other colour on the page: go back to step 3.
5. **Test** in a hidden Chrome on the Mac with stand-in clips (the template README's Mac notes, nothing to install): ffmpeg `testsrc` (it draws its own time stamp) with each clip's id as a `compare_video/label.swift` PNG on top (no drawtext here, untested), same names, some left out on purpose. Read back four numbers: clips playing with a tall window (all present ones), pair drift after 12 s (under 0.04 s), the missing ids (exactly the ones left out), page width at 390 px (no side scroll). Whole-video pairs count in the drift check too. Then test the notes against a test notes folder, never his real file. An empty box gives a faded button. Nothing is sent before a click. Shift Return and a word still being typed send nothing. One click or Return logs one line. Send all with 3 drafts logs 3 lines in board order. With the server off, the line is red and the text stays. One number wrong: go back to step 3, fix the page, then test again.
6. **Deliver.** Write the round folder and its link, top rule 2. Start both servers (8765 for clips, 8766 for notes), and keep this session watching the notes log. Open it with `open -a "ego lite"`. Then send it as a file card plus its Mac path (`llllloc:task-sending-files`).
