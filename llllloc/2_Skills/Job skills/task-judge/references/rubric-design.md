# RUBRIC: DESIGN

JOB: score an art direction deck, slides, a layout option row, a key visual or a UI screen.

INPUT: every frame at full size, the design system file, the brand file, his notes.

STEPS: look at each frame at full size, then all frames at phone size. Score every line 1 to 5 with the frame number as evidence.

OUTPUT: the scored table, the default test, the fixes.

RULES
- R1. The client sees the deck on a phone first. Why: most review links open on a phone. Check: was every frame looked at once at phone width?
- R2. A reference teaches layout, never type. Why: his fonts are part of his voice (9 Sep 2026). Check: are his fonts unchanged?

CHECK: every line below has a score and a frame number.

| # | Line | 5 means |
|---|---|---|
| D1 | One idea per frame | You can say what each frame is for in one sentence. |
| D2 | One strong move | Each frame spends its boldness in one place. Everything else is quiet. |
| D3 | The skeleton test | With the words removed, the structure alone still shows what matters most. |
| D4 | Safe zone and edges | No text touches an edge. No overlap. No lonely word at a line end. |
| D5 | Readable at phone size | The smallest text a client must read can be read at phone width. |
| D6 | Obeys the system | Colors, type, spacing come from the design system and the brand file. Fonts are his. |
| D7 | Options really differ | In a LAYOUT OPTIONS row, each option differs on a named axis, not only in color. |
| D8 | No AI-design tells | No default cream and terracotta, no tracked-out micro-labels everywhere, no card grid by habit. |
| D9 | Finished | Nothing placeholder. Names, numbers and captions are real. Every frame ends visible, nothing hidden. |
| D10 | Not the default | The default test passes: this is not the template look for this kind of deck. |
